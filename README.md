# Fanqie Novel Downloader

A modern, efficient downloader for Fanqie Novels, built with Python and featuring a clean, responsive web interface.

## Features

-   **Book Search**: Easily search for books by title or author.
-   **Batch Download**: Download multiple books at once.
-   **Format Support**: Export as **TXT** (plain text) or **EPUB** (e-book) files.
-   **Cover Images**: Automatically retrieve and embed book covers into EPUB files.
-   **Chapter Selection**: Download entire books, specific ranges, or manually selected chapters.
-   **Cross-Platform**: Supported on Windows, macOS, Linux, and Termux (Android).

## Installation
### Windows / macOS / Linux

1.  **Download**: Get the latest version from the [Releases page](https://github.com/POf-L/Fanqie-novel-Downloader/releases).
2.  **Run**:
-   **Windows**: Execute the `.exe` file. 
-   **Linux/macOS**: Grant execution permissions (`chmod +x ...`) and run the binary file.

### Source Code (Python)

Requirements: Python 3.7+

1.  Clone the repository:
```bash
git clone https://github.com/POf-L/Fanqie-novel-Downloader.git
```
